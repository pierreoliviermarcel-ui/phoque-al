# Remote

Android companion app for the Phoque Al phone remote.

- Finds the PC on the local network automatically (Wi-Fi, or the phone's own hotspot) — no QR code, no address to type.
- Full screen, screen kept on, phone volume buttons control the volume.
- Remembers the access code even when the PC's address changes.

Install: download `Remote.apk` from the Releases page and open it on the phone (allow "install unknown apps").
On the PC, open **⋯ → Phone** and enable the remote (and *Allow through firewall* once).
